# 한국어 아이콘 검색 정보

공식 이름 5,166개를 고정된 Tabler 메타데이터와 대조해 한국어 이름과 검색어를 생성합니다.
`lexicon.mjs`는 일반 용어, `brands.mjs`는 브랜드 표기, `special-terms.mjs`는 약어와 문맥에 따른 예외입니다.
`icon-labels.ts`의 기존 153개 이름과 검색어는 그대로 우선 적용합니다.

합성 이름은 검수한 용어를 조합하고, 심박수·통화·웹 요청·관계처럼 직역이 부정확한 이름은 가장 긴 구문 예외를 적용합니다.
새 용어를 영어 이름으로 대체하지 않습니다. 번역·브랜드·분류 누락, 중복된 공식 이름·한국어 이름, 빈 이름·검색어, 알 수 없는 구문 예외는 생성 오류입니다.
공식 태그는 검색 시 영문 이름·한국어 이름·한국어 검색어와 함께 사용합니다.

Docker에서 `node scripts/icon-docs.mjs`로 packed 패키지의 정적 데이터를 생성하고,
`node scripts/icon-docs.mjs --check`로 전체 생성 결과의 일치를 검사합니다.
`node --test tests/icons-package.test.mjs`는 전체성, 기존 검색어 보존, 한국어·영문 검색과 재생성 일치를 확인합니다.
