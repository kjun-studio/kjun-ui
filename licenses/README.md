# Third-party licenses and asset records

## Icons

Tabler Icons — `Tabler-LICENSE` (MIT). The build copies it next to each package's `dist/styles.css`.

## Fonts

- Inter and 42dot Sans: installed `@fontsource-variable` packages; their SIL licenses are copied beside the generated font files.
- Pretendard 1.3.9 (https://github.com/orioncactus/pretendard/tree/v1.3.9): `Pretendard-LICENSE` (SIL OFL). The preview build copies it to `apps/docs/public/fonts/`.

## KJUN brand asset

- File: KJUN — Publisher Brand Identity (Penpot), page "02 · B Master Assets"
- Exported shape: KJUN-B-Symbol-Black

The SVG in `apps/docs/public/brand` is the original Penpot export with its 320×240 viewBox and path geometry intact.

## Color ownership

Packages define color roles only. Applying projects own their color and font values; documentation-only demo palettes live in `shared/demo-colors.ts`.
