# 신규 컴포넌트와 레시피

KJUN은 자체 계약으로 12개 컴포넌트를 추가하며 공개 카탈로그는 80개입니다. 세 플랫폼의 이름과 역할은 같고 실행 환경에 필요한 이벤트·접근성 차이는 각 API 문서에서 확인합니다.

## 상태와 상호작용

- ListRow의 주 행동은 앞 영역·제목·설명·뒤 정보를 포함합니다. 보조 행동은 형제 actions 영역에 배치합니다. 상호작용 요소를 주 행동 안에 중첩하지 마세요. ListSection은 목록 구조만 제공합니다.
- TopNavigation과 BottomNavigation은 라우터를 포함하지 않습니다. 웹은 href를 제공하고 SPA 이동 콜백에서 필요한 경우에만 기본 링크 동작을 취소하세요. 현재 목적지 value는 라우팅 결과에 맞춰 앱이 갱신합니다.
- 상하단 컴포넌트는 일반 흐름에 배치합니다. 앱이 안전 영역과 키보드 상태를 전달하고 마지막에 표시되는 영역에만 하단 안전 여백을 적용합니다. 키보드 표시 시 Navigation은 기본적으로 숨기고 ActionBar는 유지합니다. 앱의 창 크기·키보드 회피 로직과 함께 사용하세요.
- Image는 요청별 완료·실패를 구분합니다. 주소가 바뀌면 이전 요청은 무시합니다. Native source는 src보다 우선하며 로컬 리소스를 지원합니다. Avatar의 fallback → 이름 첫 글자 → 기본 아이콘 순서는 표시용이며 전체 접근성 이름은 유지합니다.
- Chip은 삭제 요청만 전달합니다. 소비자가 항목을 지우고 적절한 다음 항목이나 입력으로 포커스를 이동합니다. 값 선택은 ButtonGroup, 필터는 FilterGroup, 패널 전환은 Tabs를 사용합니다.

## 숫자와 시간

Slider와 RangeSlider는 min 기준으로 step에 맞춰 이동합니다. max가 단계와 맞지 않으면 max 이하 마지막 단계가 실제 상한입니다. 두 손잡이의 순서와 접근성 이름은 유지됩니다. 입력 변경과 조작 완료는 별도 이벤트입니다.

QuantityStepper는 정밀도 0~6자리와 안전한 정수 스케일 범위를 지원합니다. 입력 중 문자열과 확정된 숫자는 다릅니다. Enter·blur에서 절반을 0에서 먼 쪽으로 반올림한 다음 범위로 제한합니다. step은 버튼 증감 단위이며 직접 입력을 step 배수로 강제하지 않습니다. 공백·잘못된 형식·안전 범위 초과는 이전 확정값으로 돌아가고 invalid-input/onInvalidInput을 알립니다. 한글 조합 중 확정하지 않으며 Escape는 편집을 취소합니다. 미확정 문자열은 복사 코드로 복원하지 않습니다.

TimePicker는 기존 Select를 사용합니다. minute는 HH:mm, second는 HH:mm:ss, 빈 값은 null입니다. min/max는 같은 형식으로 같은 날짜 안의 범위를 지정합니다. 간격은 분·초마다 0부터 시작하며 가능한 조합만 표시합니다. 빈 상태에서 구간을 선택하면 나머지를 유효한 최소 조합으로 완성합니다. 날짜·시간대·자정 너머 범위는 다루지 않습니다.

## 문서와 생성

신규 계약도 예제 레지스트리의 같은 정의에서 실행 모듈과 복사 코드를 생성합니다. 한국어·영어 검색, API 설명과 상태 소유권, 플랫폼별 도해와 상태 비교, 갤러리 썸네일을 제공합니다. /usage-guide의 범용 목록·모바일 화면·입력 설정·하단 Drawer·Thumbnail·분할 선택을 참고하세요.

카탈로그의 sources는 각 플랫폼의 실제 구현 파일을 기록합니다. 기본 빌드는 공개 export·타입·문서·packed 소비 환경을 검증합니다.

Node/npm 명령은 kjun_ui_dev 컨테이너에서 실행합니다. Native Web 검증을 iOS·Android 기기 검증으로 간주하지 않습니다. 검증 결과는 [v0.3.0 검증 기록](verification-v0.3.0.md)에 기록합니다.
